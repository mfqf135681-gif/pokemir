### all-in 识别(独立承重桩,2026-06-09 两段录像验收 ✅)
- **信号 = stack→0 稳定**:all-in → 持有筹码归 0 直到摊牌(独立观测 / 持久 / 非循环,符合"抓持久态")。
- **否决三条**:星星(瞬态,帧率天花板,全帧仅 5/9);胜率%(非 all-in 必出,R15 错前提已拆);"ALL IN" 字(裸头像渲染,难从多变头像分离)。
- **事件合并**:0/None 连续算一次、**遇确认筹码数字才断**(同手内 None 碎片合并 / 跨手真多次分开);amount = 归 0 前最后正数读。**不可按游程长短过滤**(实证:仅 10 帧也是真 all-in)。
- **验收**:召回 20/20=100%(含双 all-in)、金额准、单帧 0 噪声=0。
- **唯一假阳 = 座位易主【过渡】**(非"空座"本身):稳定空到终局(s7)读 None → 安全;空→新人补入的过渡(s3)冒瞬态 0 → 假事件。
- **去伪闸 = card_marker 活跃集(本手持牌)** 为主,**非 raw occupancy**(过渡期占位会闪、且易主座终局已占位,"现在占位吗"会漏过);辅以"本手有过正 stack 才归 0"同手模式。座位易主属 #241 范畴。
- **下一步**:活跃集闸清过渡假阳 → 喂 `reconstruct.allin_marks`(narrow 拆 % 时留的来源无关消费接口)。
- 工具:`tools/probe_stack_zero.py`(事件合并探针)。详见 [[allin-pillar-must-be-persistent]]。
