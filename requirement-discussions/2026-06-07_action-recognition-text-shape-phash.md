## 0. 一句话
动作识别**不靠颜色、不靠 OCR**。每座 action_area:**饱和度抠白字 → 文字外接框裁出 → resize 归一 → 8×8 aHash → 比各动作参考(跟注/加注/下注/过牌),hamming≤阈 → 该动作;全落空 → 无动作。** 色盲、位置无关、词表小。

## 1. 演进:为什么不是颜色、不是 OCR(留痕,别再走回头路)
- **OCR(EasyOCR/recognize-only)**:慢 + idle 被 allowlist 逼出垃圾;动作区纯色填充下根本不该读字。弃。
- **颜色(平均色判别)**:一度成立(加注橙/跟注蓝/过牌绿),但 **🔴 实测下注(bet)橙/蓝/绿三色都有(用户翻图库证实)→ 颜色污染每个组(橙=加注∨下注…)→ 颜色不再是干净分类器**。死。
- **灰度 phash(_avg_hash_64 全图)**:色盲不够——底色亮度不同 + aHash 比均值会随底色翻转 → 同动作散成多簇;且**各座 action_area 相对位置不一**,aHash 非平移不变 → 跨座匹配不上。
- → **正解:抠白字 + 位置归一,再 hash。** 文字是每个动作的不变量,色盲+位置无关一并解决下注多色与位置不一。

## 2. 定型方法(`text_shape_hash`,探针已实现)
```
crop(action_area)
 → HSV,(S < sat_th) & (V > val_th) = 白字 mask        # 抠字,排除高饱和底色 → 色盲(治下注多色/桌皮)
 → 文字外接框裁出                                       # 去"在框里哪个位置" → 治各座 ROI 相对位置不一
 → resize 32×16                                         # 去尺度
 → 8×8 aHash → 64位"0/1"串(同 _avg_hash_64 格式)
比对:min hamming 到各动作参考集;≤阈 → 该动作;全 > 阈 → 无动作(idle)
```
- 复用 `pipeline.orchestrator._hamming`(card_marker 基桩同套)。
- 参数 `sat_th≈60 / val_th≈100`(白字阈,可调;非白字时调)。

## 3. 为什么成立 + 实测验收
**成立**:色盲(治下注多色/换桌皮)· 平移/尺度无关(治各座框位置)· 动作词表仅 5 个(跟注/加注/下注/过牌/弃牌)· 文字是动作不变量。
**实测(`probe_action_phash --text-mask`,录像 20260603_121925,3224 crop,单参考/动作):**
| 动作 | @hamming≤6 命中 | 干净度(眼标) |
|---|---|---|
| 过牌 check | 34(全绿) | 全"过牌";vs idle(ID 字落 30+)分开 ✅ |
| 加注 raise | 37(全橙) | 全"加注",**无下注混入** ✅ |
| 跟注 call | 18(全蓝) | 全"跟注" ✅ |
| 下注 bet | 5(4橙+**1绿**) | 全"下注";**1 绿=多色下注被橙参考匹配上→多色塌一簇证据** ✅ |

**带"注"三兄弟(跟注/加注/下注)靠第一字(跟/加/下)分开;下注多色塌成一簇;idle 被拒。** 合成单测另证:同字跨色/平移 hamming=0,异字=34,纯色无字→""。

## 4. 范式:逐动作二元桩(card_marker 式)
每动作一个(组)参考,**二元判断**(命中→该动作 / 落空→无动作),独立检测器。降级优雅:命中唯一→该动作;同时命中多个→歧义,交游戏状态(§15 解不读);一个没中→idle(动作持久态,下 tick 再抓)。

## 5. 实装计划(#240)
1. **多参考/动作**:不同座 + 视觉态(高亮/动画)各采几个,任一命中=该动作(抗抖动;单参考已干净,多参考更稳)。
2. **参考存文件**:像 `rois/digit_templates_<profile>.json`,live 读;桌皮换→重采(见 §7)。
3. **阈值**:实测低簇 ≤6-12、idle 30+,**阈 ≈8-10 余量大**;接入后验误命中(各参考拒 idle + 拒其他动作)。
4. **接 orchestrator**:每座每 tick `text_shape_hash(action_area)` → 比参考 → 动作,**替 action OCR**。
5. **fold/all-in** 不在动作区 → 头像区(#235)。

## 6. 顺手解频率瓶颈(对照)
action OCR(242ms/27% tick)→ `text_shape_hash`(抠字+resize+aHash,微秒级)。配 #235(fold/all-in 头像区 phash 替 417ms fold OCR),**两大头共 73% tick 换近免费 → 投影 ~7Hz,recognize-only(#237 已 park)+ 解耦均不用**。

## 7. 缺口 / 严限
- **下注罕见**(本段录像仅 5 个)→ 检测器没问题(5 个全对),但多参考采集时下注样本难凑;必要时下注退游戏状态(橙/任意色 + 本街无注 → 下注)。
- **加注 vs 下注**:实测文字分开(raise 无 bet 混),但样本少;若实战粘,退游戏状态(本街有注=加注/无注=下注)。
- **白字阈** sat_th/val_th 依赖文字是白色;非白需调或改抠字法。
- **桌皮**:文字形状对换皮鲁棒(色盲),但若字体/字号变仍需重采参考 → 预留空桌/全桌重采工具(backlog,见 capture-frequency doc §6 同条)。
- **颜色降级为辅**:不做主判别,仅"自动认座/采参考"时帮快速分组。
