## 2. 假设清单
1. recognize-only 跳过检测 ×3.1 —— 出处:`tools/bench_ocr.py` path C 实测(本会话 run_bench_tick.cmd)。
2. `reader.recognize(grey, horizontal_list, free_list, detail=0)` 返回**按 box 顺序的字符串列表,1-1** —— 出处:**context7 /jaidedai/easyocr**(detail=1 返 `(bbox,text,conf)`,detail=0 返 text;free_list=[] → 仅 horizontal_list 顺序)。
3. ROI 坐标为**帧内相对**(帧 [0,0]=窗口原点)—— 出处:`capture/screen.py:159` capture_roi 切片 `_frame[roi.top:.., roi.left:..]`。
4. 整帧缓存于 `capturer._frame`(**BGRA**,D.1 杠杆每 tick refresh)—— 出处:`capture/screen.py:147`。
5. action 读经 `_capture_with_diff_trigger`(T52 像素差缓存 9.17x + ensemble)—— 出处:`orchestrator.py:1910/2293`。

**盲区(分诊 = Win-only,非 blocker,见 §6/§7):**
- B1 准度:bench 只测速未测准;recognize-only 跳过 `_read_one` 的 otsu/upscale 预处理(recognize 内置 `contrast_ths/adjust_contrast` 部分缓解)。
- B2 真实倍数:×3.1 是固定帧单 allowlist 上界,实战按 allowlist 分组后更低。

## 3. 文件变更清单
| 文件 | 变更 | 说明 |
|:---|:---|:---|
| `config.py` | 新增 | `OCR_RECOGNIZE_ONLY`(默认 0,依赖 `FRAME_CAPTURE=1`) |
| `recognition/ocr.py` | 新增方法 | `recognize_boxes(frame_grey, boxes, allowlist, batch_size)` —— 包 `reader.recognize`;detail=0/free_list=[];异常/不齐/None → "" 占位补满 len(boxes) |
| `capture/screen.py` | 新增方法 | `get_cached_frame()` —— 返回 D.1 缓存帧(避免戳私有 `_frame`) |
| `pipeline/orchestrator.py` | 新增 2 helper + 改 1 行 | `_get_tick_frame_grey()`(整帧灰度**每 tick 算一次**缓存)· `_recognize_only_roi(roi, allowlist)`(单 ROI 框,坐标越界/无缓存帧→None)· `_capture_with_diff_trigger` OCR 分支(`:1952`)flag-gated 优先 recognize-only,**返 None→回退 read_text**;import 加 `OCR_RECOGNIZE_ONLY` |

**设计要点**:与 T52 diff 缓存**叠加**(只对"变了的座"调,整帧灰度图每 tick 仅 cvtColor 一次);flag 关 = 行为**逐字节不变**(同 DIGIT_RECIPE_LIVE/BUTTON_CUT 安全模式);任何不可走条件(FRAME_CAPTURE 关/坐标越界)自动回退,**零风险**。recognize-only 路径不跑 ensemble(放弃 2x/3x 双读,这正是提速点)。
